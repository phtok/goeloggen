# Apps

Statische Goetheanum-Onepager mit jeweils eigenem Einstieg unter `index.html`.

- `logos/` - Logo-Generator (Slug `logo-generator`)
- `gtv-naming/` - GTV Naming – Renderings
- `visitenkarten-generator/`
- `briefschaften/`
- `karten-generator/`
- `cover-generator/`
- `signatur-generator/` - E-Mail-Signatur-Generator (table-basiertes HTML, Inline-CSS)

## Altlink – nicht loeschen

- `logo-generator/` ist **keine App**, sondern eine Weiterleitung auf `logos/`.
  Der Generator hiess bis Juni 2026 so, und die alte Adresse
  `werkzeuge.goetheanum.ch/apps/logo-generator/` ist auswaerts an vielen Stellen
  hinterlegt (Mails, Praesentationen, fremde Seiten). Sie bleibt bestehen, bis
  die kurze Adresse `/logo-generator/` sich etabliert hat. Erst entfernen, wenn
  bekannt ist, wer die alte Adresse noch verlinkt.
