# Begleitschriften

Installiert mit den Goetheanum-Schriften (`../Installer/`), gebaut von
`tools/goetheanum-fontfix/build_begleitschriften.py`.

| Familie in Office | Dateien | Herkunft | Im Installer |
|---|---|---|---|
| Source Sans 3 | `SourceSans3-Regular/-It/-Bold/-BoldIt.ttf` | Adobe 3.052R, unverändert | Standard |
| Source Sans 3 Semibold | `SourceSans3-Semibold/-SemiboldIt.ttf` | Adobe 3.052R, unverändert | Standard |
| Goetheanum Kyrillisch | `GoetheanumKyrillisch-Regular/-Bold.ttf` | Titillium Web [RUS by Daymarius], umbenannt | `-Kyrillisch` / `--kyrillisch` |
| Goetheanum Arabisch | `GoetheanumArabisch-Regular/-Bold.ttf` | Cairo, statisch (400/700), umbenannt | `-Arabisch` / `--arabisch` |

Lizenzen: `LICENSE-SourceSans3.md` (SIL OFL 1.1, Reserved Font Name
«Source»: darum unverändert und unter eigenem Namen) und
`OFL-Kyrillisch-Arabisch.txt` (SIL OFL 1.1, Originale ohne Reserved Font
Name, fsType 0).
